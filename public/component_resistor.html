Resistors

An Electrical component that limits or regulates the flow of electrical current (creates resistance) in an electrical circuit

Symbol

The unit of resistance is ohms.

One Ohm is 1 volt (electric potential difference)/1 amp (unit of current)

Fixed Resistors: the resistors that have a fixed resistance

Application of a resistor in a circuit: Resistors are used to reduce current (the flow of electrons) in an electrical circuit

When Resistors are connected in parallel

Types of Resistors

Resistors are available in different size, Shapes and materials. Different types of resistors are given below with details

Linear Resistors

Those resistors, which values change with the applied voltage and temperature, are called linear resistors. In other words, a resistor, which current value is directly proportional to the applied voltage is known as linear resistors. Generally, there are two types of resistors which have linear properties.

  • Fixed Resistors: As the name tells everything, fixed resistor is a resistor which has a specific value and we can’t change the value of fixed resistors.
  • Variable Resistors: Resistors where the user can change the value/the amount of resistance.

Types of variable Resistors
